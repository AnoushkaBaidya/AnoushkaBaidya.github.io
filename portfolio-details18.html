Real-Time Speech Translation

Production ML  ·  Real-Time Inference  ·  NLP

  • Bidirectional EN↔JA live speech translation pipeline deployed for manufacturing meetings, achieving 115–206ms end-to-end translation latency.
  • Built on Deepgram STT for streaming transcription, a FastAPI WebSocket server for low-latency delivery, and a React frontend with rolling caption revision.
  • Incorporates domain-adapted glossary normalization to handle manufacturing-specific terminology accurately across languages.
  • Containerized with Docker and designed for zero-downtime production deployment; handles concurrent sessions with asynchronous processing.
